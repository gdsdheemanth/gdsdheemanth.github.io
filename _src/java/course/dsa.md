## Hands-on mini projects

Build at least two of these before moving on. Put each on GitHub with a short README.

### LLD: Parking Lot (Intermediate)

Multiple floors, vehicle types, spot allocation strategies, tickets and fees. Class diagram first, then working Java code with tests.

**Practises:** OOP design, Strategy/Factory patterns

### LLD: LRU Cache + in-memory Key-Value store (Intermediate)

LRU cache (HashMap + doubly linked list), then a thread-safe key-value store with TTL expiry and a simple command interface.

**Practises:** Data structures, concurrency

### LLD: Rate Limiter (Advanced)

Token bucket and sliding window implementations behind one interface, thread-safe, with tests; then a Redis version used by a Spring filter.

**Practises:** Algorithms, concurrency, design

### HLD write-up: URL Shortener (Intermediate)

A 2-page design doc: requirements, API, data model, ID generation, caching, scaling, diagrams. Then compare it with your Spring URL shortener mini project.

**Practises:** System design communication

### Pathfinding Visualiser (Intermediate)

A React app that animates BFS, DFS and Dijkstra on a grid. Fun to show, and it makes graph algorithms stick.

**Practises:** Graphs, BFS/DFS, React
