Projects and interview skills matter much more than certificates. Do a certificate only if it fits into your schedule without delaying the projects.

Java + Spring Boot + React is one of the most hired-for stacks in India, across product companies, global capability centres (GCCs), IT services and startups. With about 1 year of total experience (6 months full-time + 6 months internship), you fit **0–2 year** and **1–3 year** openings, as well as associate and graduate programs.

**Be honest about experience:** write "1 year (including a 6-month internship)" or list them separately. Many recruiters count only full-time months; don't stretch it. Your projects make up the difference.

## Job titles to search for

- Associate Software Engineer / Software Engineer I / SDE-1
- Java Developer (0–2 yrs) · Java Full Stack Developer · Java Backend Developer
- Full Stack Engineer (React + Spring Boot) · Application Developer · Programmer Analyst
- Associate Consultant (Java) · Graduate / Associate Engineer programs

**Search keywords:** `Java Spring Boot 0-2 years`, `Java full stack React`, `Spring Boot microservices 1 year`, `Java backend developer fresher`, `React Spring Boot developer`.

## Where to target

### A. Internal move (fastest route)

Ask your current manager or HR whether you can transfer to a development team inside the company. Meanwhile, volunteer for any scripting, SQL tooling, automation or API work. That gives you real development experience to put on your resume.

### B. Product companies and global capability centres (GCCs)

India has thousands of engineering centres of global companies (retail, e-commerce, SaaS, travel, telecom, healthcare, manufacturing and more), and many run Java/Spring backends with React frontends. Search LinkedIn for "Java Spring Boot React" filtered by 0–2 years, and check career pages of companies whose products you use.

### C. IT services and consulting (high volume, easier entry)

TCS, Infosys, Wipro, HCLTech, Cognizant, Accenture, Capgemini, LTIMindtree, Tech Mahindra, Virtusa, Hexaware. They hire Java full stack developers in large numbers, and moving between projects later is common.

### D. Startups (fast learning, broad ownership)

Use Wellfound, Cutshort and Instahyre. Check the tech stack in every post (some use Node/Go/Python). Expect DSA + machine-coding rounds and a deep discussion of your projects.

## Resume: present your current role in technical terms

- **One page.** Headline: *"Software Engineer | Java · Spring Boot · React · Kafka · Microservices · SQL"*.
- **Summary (2 lines):** about 1 year of IT experience with strong SQL, data and production-support skills; builds full stack apps with Java, Spring Boot, React and Kafka.
- **Order:** Summary → Skills → Projects (ShopSphere first) → Experience → Education/Certifications.
- **Write the current-role bullets around technical skills** (SQL, data handling, troubleshooting, automation) and add your real numbers: "Wrote and optimised SQL queries to investigate data issues across large datasets, cutting investigation time by Z%."
- "Configured and maintained rule-based data processing for N data sources handling ~X records/day."
- "Supported production runs: diagnosed failed data feeds and coordinated fixes with upstream teams within SLA."
- "Automated [a report/check] using [SQL/scripts], saving N hrs/week."

**Project bullets:** stack + what you built + one hard problem you solved + a link (e.g. "Prevented overselling under concurrent orders using optimistic locking and a Kafka-based Saga"). **ATS:** copy the exact keywords from the job description (Spring Boot, REST, Microservices, Kafka, JPA/Hibernate, React, TypeScript, SQL, JUnit, Docker, AWS, Agile/Scrum). Use a simple layout: no tables, columns or photos. Put the GitHub, LinkedIn and live demo links at the top.

## LinkedIn and Naukri setup

### LinkedIn

- Headline the same as the resume headline.
- "Open to work": recruiters only (so your current employer doesn't see a public banner).
- About section: your switch story in 4–5 lines.
- Featured: ShopSphere repo + demo video.
- Post your learning progress weekly. Recruiters do notice.
- Connect with Java/React developers, engineering managers and recruiters at your target companies.

### Naukri / Instahyre / Hirist

- Resume headline full of keywords.
- Key skills: add all the relevant tech (up to the limit).
- Update the profile every 2–3 days (it pushes you up recruiter searches).
- Fill in notice period and expected CTC honestly.
- Set job alerts for the titles above.

## Weekly application system

- **10–15 targeted applications per week** (resume tweaked to each job description's keywords) rather than 100 untargeted ones.
- **5 referral requests per week** on LinkedIn. Referrals get far more callbacks than cold applications.
- Track everything in a sheet: company, role, date, source, referral (Y/N), status, next step, follow-up date.
- Follow up once after 7–10 days.
- After every interview, write down every question you were asked and add the weak ones to your revision list.
- Expect a typical process: online test (DSA/MCQ) → technical round 1 (Java + Spring) → technical round 2 (projects + design/SQL/React) → manager round → HR.

## Optional certifications (nice to have, not required)

- Oracle Certified Professional: Java SE 17 (1Z0-829) or Java SE 21 (1Z0-830) Developer
- Spring Certified Professional (VMware/Broadcom)
- AWS Certified Cloud Practitioner → Developer Associate
- Professional Scrum Master I (PSM I), useful for Agile questions

## Offer stage

- Research salary ranges on AmbitionBox, Glassdoor and Levels.fyi for the exact role and city.
- A switch is usually a good time for a raise. Give a researched range, not one number.
- Compare the learning (tech stack, mentoring, code quality), not just the CTC. Your first dev role sets your next 5 years.
- Don't resign before you have a written offer letter. Plan around your notice period.
