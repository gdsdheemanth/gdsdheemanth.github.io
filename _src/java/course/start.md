**Your situation:** 6 months internship + 6 months full-time on IntelliMatch (data reconciliation). You want to become a **Java Full Stack Developer** (Java + Spring Boot + React + Kafka + Microservices + SQL). **How to use this guide:** learn the topics in each tab in order, build the **mini projects** at the bottom of every tab to get hands-on, and alongside them build the **combined project, ShopSphere** (see the *Combined Project* tab), which brings every topic together. That is the project you show in interviews. Your current experience still helps: SQL, working with data, production support and working in a professional team all carry over to development.


## 24-week roadmap (about 2–3 hrs on weekdays + 6–8 hrs on weekends)

| Weeks | Focus | Output by the end |
|---|---|---|
| 1–4 | Core Java (OOP, collections, exceptions, generics, Java 8+ streams), Git basics, SQL refresh, 1 DSA problem per day | Core Java + SQL mini projects; **ShopSphere Phase 0** started; 25+ DSA problems |
| 5–6 | Advanced Java: concurrency, JVM, modern Java (17/21/25), Maven, JUnit 5 | Advanced Java mini projects; **ShopSphere Phase 0** (pure-Java core) done |

| 11–13 | HTML/CSS → JavaScript → TypeScript → React | **ShopSphere Phase 2** (React + deployed v1) done. **Resume + LinkedIn ready; start applying in week 12** |
| 14–17 | Microservices patterns, Docker, Kafka, Spring Kafka | Kafka mini projects; **ShopSphere Phases 3–4** (microservices + Kafka) done |
| 18–20 | Kubernetes basics, CI/CD (GitHub Actions), AWS basics, observability | **ShopSphere Phase 5** (Kubernetes, CI/CD, cloud, monitoring) done |
| 21–24 | LLD + HLD basics, mock interviews, revision of the question bank | **ShopSphere Phase 6** (load tests, design doc, demo); applying heavily; 120+ DSA problems |

**Don't wait until you've "finished everything" to apply.** Nobody finishes this list. Apply once you have core Java, Spring Boot and one solid deployed project (about week 12). Keep learning while you interview.

## Daily routine that works

- **30–45 min:** 1 DSA problem in Java (easy → medium).
- **60–90 min:** the current roadmap topic (docs or course, then code it yourself).
- **30 min:** build the project feature that uses what you just learned.
- **Weekend:** a bigger project chunk + revise 20 interview questions + 1 mock interview (with a friend or a recording).

## Version notes (late 2026)

- **Java:** learn on **Java 21 LTS** (most widely used in companies). Know what's new in **Java 25 LTS**. Many companies still run Java 8/11/17, so know the differences.
- **Spring Boot:** most jobs use **3.x**; **4.x** (Spring Framework 7) is the newest. The concepts are the same. Learn on 3.x/4.x, never 2.x tutorials (they use the old `javax.*` package names; new code uses `jakarta.*`).
- **React:** React 19 with **Vite**. Create React App is deprecated, so skip tutorials that use it.
- **Kafka:** Kafka 4.x runs in **KRaft mode** (ZooKeeper has been removed). Older tutorials with ZooKeeper are fine for concepts only.
