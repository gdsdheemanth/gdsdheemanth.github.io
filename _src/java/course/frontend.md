## Hands-on mini projects

Build at least two of these before moving on. Put each on GitHub with a short README.

### Responsive Portfolio Website (Beginner)

Your personal site in HTML + CSS (flexbox/grid), mobile-first, deployed on Netlify. Later, link all your projects here.

**Practises:** HTML, CSS, responsive design, accessibility

### Weather App (Beginner)

Search a city, show current weather + 5-day forecast from a free weather API, loading and error states, debounced search.

**Practises:** JavaScript, fetch, async/await, DOM, debounce

### Kanban Board (Intermediate)

React + TypeScript board with columns, add/edit/delete cards, drag and drop, filters, saved in localStorage.

**Practises:** useState, useReducer, Context, TypeScript

### Movie Explorer (Intermediate)

Search movies from a public movie API, infinite scroll, detail pages via React Router, favourites list, skeleton loaders.

**Practises:** React Router, TanStack Query, custom hooks

### Admin Dashboard for your Spring API (Advanced)

Login with JWT against your Blog/Job Board API, protected routes, tables with server-side pagination, charts, forms with React Hook Form + Zod, tests with React Testing Library.

**Practises:** Auth flow, forms, data fetching, testing
