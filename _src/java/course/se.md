## Hands-on mini projects

Build at least two of these before moving on. Put each on GitHub with a short README.

### Run ShopSphere as Scrum (Beginner)

Create a GitHub Projects or Jira board, write user stories with acceptance criteria, estimate in story points, work in 2-week sprints and keep short retro notes.

**Practises:** Scrum, user stories, estimation

### Refactoring kata: Gilded Rose (Intermediate)

Take this famously messy code, add tests first, then refactor it using SOLID and the Strategy pattern without changing behaviour.

**Practises:** Refactoring, SOLID, code smells

### Design-pattern mini library (Intermediate)

Implement 10 GoF patterns in Java with a realistic example and test for each (e.g. Builder for HTTP requests, Observer for events, Decorator for logging).

**Practises:** Design patterns

### Contribute to open source (Advanced)

Find a 'good first issue' in a Java/Spring or React project, follow its contribution guide, open a PR and respond to review comments.

**Practises:** Git workflow, code review, collaboration

### Write ADRs & docs (Beginner)

Add Architecture Decision Records, a proper README, API docs and a CONTRIBUTING guide to ShopSphere.

**Practises:** Documentation standards
